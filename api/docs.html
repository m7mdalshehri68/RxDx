One engine, not two

    
This service does not re-implement the coding logic. It loads the very same script that runs in the doctor's
      browser and calls the same functions. An API that reimplements the engine drifts away from the tool within a month,
      and then two answers exist for the same note and nobody can say which is right. A parity test runs the whole
      labelled corpus through both and fails the build the moment they disagree.

    
What this service does not do: it does not check drug interactions, renal or hepatic dose adjustment,
      pregnancy or breastfeeding, and it does not decide medical necessity. It reads text and proposes codes.
      A person signs the note.
