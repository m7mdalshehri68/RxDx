# Icons

The Nocturne icon set as standalone SVG files: 24 × 24, 1.6 stroke, round caps and joins, no fill.

Each file's ink is baked in as `cyan` (`#22e4ff`), because an `<img>` cannot inherit `currentColor`. In React, use the `Icon` component instead: same glyphs, any colour.
